# Static Website Starter

A simple website starter built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main page markup
- `styles.css` — responsive styling
- `script.js` — mobile menu + form handling

## Run locally

Open `index.html` in your browser, or use a simple local server like Live Server in VS Code.

## Customize

Update the page content, colors, and layout in `index.html` and `styles.css` to make this site your own.
